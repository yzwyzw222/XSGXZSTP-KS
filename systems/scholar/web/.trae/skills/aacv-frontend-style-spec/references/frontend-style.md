# AACV 前端样式参考

## 1. 技术基线

- Vue 3.5
- Vue Router 5.3
- Element Plus 2.14.5
- 原生 `fetch`
- ECharts 用于统计图，Cytoscape 用于关系图
- Vite 保持 `/api` 与 `/actuator` 路径不变并转发至后端

当前项目不使用 Pinia、Axios 或自动导入。新增状态或请求能力前，先复用现有 composable、模块状态与 API 客户端。

## 2. 颜色令牌

| 语义 | 值 | 用途 |
|---|---|---|
| `--ink` | `#edf6ff` | 主文本、深色背景上的高强调内容 |
| `--muted` | `#8296ae` | 次要文本、说明、占位信息 |
| `--paper` | `#10233d` | 主卡片和内容面 |
| `--paper-deep` | `#0b1c31` | 深层面板、输入或嵌套区域 |
| `--raised` | `#142a46` | 悬浮或高层级卡片 |
| `--accent` | `#2d9df5` | 主按钮、当前状态、重点数据 |
| `--accent-bright` | `#57bcff` | Hover、焦点和强调边缘 |
| `--accent-dark` | `#1579ca` | Pressed、深色强调 |
| `--green` | `#35c98c` | 成功、在线、完成 |
| `--amber` | `#f5a04b` | 警告、待处理、延迟 |
| `--danger` | `#ff6670` | 错误、失败、危险操作 |
| `--violet` | `#a77af2` | 辅助分类或图表序列 |
| `--background` | `#071225` | 应用全局背景 |
| `--sidebar` | `#0a1e38` | 固定侧栏背景 |

同一颜色必须保持语义一致。成功、警告、错误和权限状态除颜色外，必须配合文本或图标。

## 3. 字体与层级

- 字体栈优先 `Inter`、`Segoe UI`、`Microsoft YaHei` 及系统无衬线字体。
- 页面标题通常保持 24px 至 30px；卡片标题 16px 至 18px；正文和表格 13px 至 15px；辅助文本不小于 12px。
- 数字指标可使用更高字重，但避免为所有文本同时加粗。
- 使用行高、字重和间距建立层级，不以多种字体或过多色彩制造区分。

## 4. 页面骨架

- 桌面侧栏宽度：228px，固定在左侧。
- 顶栏高度：78px，保持吸顶；提供页面定位、用户信息和必要全局操作。
- 主内容从侧栏右侧展开；卡片、筛选区、表格区和详情区保持清晰分组。
- 页面间距以 12px、16px、24px 为常用档位；紧凑控件内部可使用 4px 或 8px。
- 圆角范围 4px 至 10px，边框使用低对比冷色，不依赖高强度阴影分层。

## 5. 组件规范

### 按钮

- 每个操作组只有一个主要按钮；危险操作使用危险色并在必要时二次确认。
- Hover、Pressed、Disabled、Loading、Focus-visible 状态必须可区分。
- 图标按钮提供可访问名称或 Tooltip，不能只依赖图形猜测含义。

### 表单

- Label 与输入建立明确关系；必填、格式和业务错误显示在对应字段附近。
- 登录失败使用统一消息，不提示用户名是否存在或账户具体安全状态。
- 提交期间阻止重复提交；失败后保留非敏感输入和修复上下文。

### 卡片与指标

- 卡片服务于分组，不为每一行文字单独加容器。
- 指标卡包含名称、当前值、单位或时间范围；趋势必须明确正负含义。
- 空数据展示原因和下一步，不能只显示 `0` 或空白。

### 表格与列表

- 重要标识、状态和主要操作保持可扫描；次要列可在窄屏隐藏或转为详情。
- 长文本截断时提供可访问的完整内容查看方式。
- 加载、空结果、错误、无权限和分页状态使用统一反馈。

### 图表与关系图

- ECharts 使用现有配色序列，并在 Canvas 外提供标题、单位、时间范围和必要摘要。
- Tooltip 不承载唯一信息；图例和状态标识必须对键盘与低视力用户友好。
- Cytoscape 大图维持 300 节点上限，超限时提示筛选或缩小范围。
- 组件卸载时销毁实例、监听器和动画资源。

## 6. 响应式规则

| 断点 | 主要策略 |
|---|---|
| `1180px` | 缩短横向留白，压缩多列指标与复杂工具栏 |
| `900px` | 侧栏切换为可收起或覆盖式导航，主区单列优先 |
| `680px` | 筛选和操作分行，表格切换可滚动或卡片摘要 |
| `480px` | 保留单一主任务，按钮可全宽，减少非关键元信息 |

在每个断点前后检查 1px，避免临界宽度出现水平溢出、遮挡或操作不可达。

## 7. 认证与请求体验

- API 默认超时为 12 秒；沿用 `AbortController` 支持超时与调用方取消。
- 请求使用同源凭证；CSRF Token 在内存缓存，并按后端约定添加 Header。
- 401：清理当前用户与 CSRF 状态，进入登录流程。
- 403：保留页面上下文，显示无权限说明和安全的返回路径。
- 409：提示数据已变化，刷新后让用户重新确认操作。
- 503/504：说明依赖暂不可用，提供有限重试，不使用无界自动重试。
- 请求失败时展示安全、可行动的提示；详细诊断通过 `traceId` 关联，不向用户展示底层堆栈。

## 8. 动效与资源清理

- 动效只用于反馈状态变化、进入退出和空间关系，时长保持克制。
- 在 `prefers-reduced-motion: reduce` 下禁用非必要位移、循环和视差效果。
- `onBeforeUnmount` 中清理定时器、`requestAnimationFrame`、事件监听、AbortController、ECharts 和 Cytoscape 实例。
- 避免在异步回调中更新已卸载组件；长任务必须提供明确状态或取消路径。

## 9. 交付检查清单

- 颜色、字体、间距、圆角和布局复用现有令牌。
- 登录、无权限、加载、空数据、错误、成功和冲突状态完整。
- 桌面与四个响应式断点无溢出、遮挡或不可达操作。
- 键盘焦点可见，输入有标签，状态不只靠颜色，图表有替代信息。
- Session 与 CSRF 处理遵循现有安全模型，未保存敏感认证数据。
- 所有副作用可取消或清理，未留下计时器、请求、动画或图实例泄漏。
- 相关 Vitest、构建和人工视觉检查均实际执行并如实记录。
