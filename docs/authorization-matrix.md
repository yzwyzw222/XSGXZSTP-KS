# 阶段 7 权限矩阵

## 1. 角色

| 角色代码 | 角色名称 | 阶段 7 职责 |
| --- | --- | --- |
| `ADMIN` | 系统管理员 | 管理用户、审计、数据源、采集和治理；读取图谱、统计和导出；执行图维护；读取运行总览并确认系统内告警 |
| `DATA_OPERATOR` | 数据运营人员 | 执行采集和治理；读取图谱、统计和导出；执行事件重放、回填和对账，不访问系统级运维总览或执行全量重建 |
| `RESEARCHER` | 科研用户 | 查询成果目录、来源追溯、局部图谱、受限路径和统计；导出本人有权查询的目录结果，不访问同步或系统运维接口 |

阶段7新增权限固定为：`ANALYTICS_READ`授予三个角色；`EXPORT_CREATE`和`EXPORT_READ`授予三个角色，但导出应用服务还必须执行创建者或管理员对象级校验；`OPERATIONS_READ`和`ALERT_MANAGE`只授予`ADMIN`。前端路由只能用于改善交互体验，权限判定始终由后端安全过滤器和应用服务共同执行。

原始Payload正文仅在后台保存90天，阶段7仍没有开放读取接口；每日小批清理由系统内部Quartz任务执行，不作为用户接口授权。失败分页、治理证据、质量样本、图同步事件、导出错误和系统内告警只返回有限安全信息，不返回响应正文、SQL、Cypher、内部锁标识、服务器文件路径、Authorization头、Cookie、CSRF Token、Crossref联系邮箱、完整游标或任何凭据。导出创建、事件重放、回填、对账、全量重建和告警确认均要求CSRF并记录审计；全量重建还要求显式确认字段。
