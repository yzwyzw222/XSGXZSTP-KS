# 权限矩阵

> 骨架版，随实现持续更新。前端隐藏按钮只是交互提示，后端校验才是最终权限边界。

## 角色

| 角色 | 编码 | 说明 |
|---|---|---|
| 管理员 | `ADMIN` | 管理用户与角色，全部数据操作与分析权限 |
| 普通用户 | `ANALYST` | 数据浏览、图谱与分析查询；维护自己创建的数据 |
