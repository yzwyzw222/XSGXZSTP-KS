## 3. 验证命令与结果

最终前端测试和构建在受限沙箱内加载Vite配置时，因环境禁止子进程创建而返回`Error: spawn EPERM`；在具备子进程权限的同一宿主工作区执行下列相同命令后通过。该失败属于执行环境限制，不是测试断言或TypeScript错误。

~~~powershell

~~~

结果：`BUILD SUCCESS`，123个测试全部通过，失败、错误和跳过均为0，总耗时12分13秒。测试在Docker Desktop Linux Engine可访问的宿主环境运行。

### 3.2 前端单元与组件测试

~~~powershell

~~~

结果：5个测试文件、12个测试全部通过。覆盖健康代理、CSRF请求头、204、401、403、409、超时、登录后CSRF令牌轮换、权限路由和登录表单空输入。

### 3.3 前端生产构建

~~~powershell

~~~

结果：`vue-tsc -b`和`vite build`通过；业务页面按路由拆分，未出现全量Element Plus单包体积告警。

结果：本机Microsoft Edge下3个测试全部通过，覆盖未登录回跳及成果空状态、权限不足进入403、业务请求401进入会话过期页。测试使用Playwright路由级契约响应，不读取开发数据库或真实账号。
